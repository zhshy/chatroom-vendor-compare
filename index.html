4回调机制：发送前 vs 发送后

同样是「回调」，链路位置决定审核是「先审后发」还是「先发后审」。

发送前回调先审后发 · 可拦截

客户端发消息 → IM 服务器 → 拦截副本 → 你的后端 → 放行：投递 拒绝：不下发

违规内容在投递前被拦下，聊天室里的其他人看不到。响应超时按默认策略处理。

发送后回调先发后审 · 仅抄送

客户端发消息 → IM 服务器 → 先投递并展示 → 事后抄送 → 你的后端 → 撤回 / 标记

消息已被所有人看到，只能事后撤回补救。腾讯云直播群不支持撤回消息，此路线基本无效。
